# Scientist portraits

Bundled locally for offline topic cards. Images are resized; cards display a grayscale crop. The original works remain available at the links below. Credits are also shown in each card’s tooltip. Robert Hooke and Archimedes are imagined posthumous portraits, labelled in both app languages. The Dvali–Gomez topic uses Gia Dvali’s portrait.
